# Command-line reference

The `chronicle-cli` CLI is a thin wrapper around library APIs. Every
operation it performs is also available programmatically; the CLI is the
convenient form for operators, scripts, and CI.

```bash
chronicle-cli <subcommand> [<args>] [<options>]
```

Every subcommand supports `--help` for the autogenerated flag
documentation (via the `clip` shard). Top-level `chronicle-cli --help`
lists every subcommand.

!!! note "Parity of the CLI surface"
    The upstream `activegraph` CLI exposes `inspect`, `replay`, `fork`,
    `diff`, `promote`, `export-trace`, `migrate`, `pack new`,
    `pack list`, and `quickstart`. Chronicle's `chronicle-cli` implements
    `route preview`, `diff`, `log inspect`, `replay`, `trace`,
    `session list`, `fork`, `chat`, and `quickstart`. The
    command-level operations not exposed by the binary (`promote`,
    `migrate`, pack scaffolding/listing) are available as library APIs —
    see below and [`plans/parity.md`](../../plans/parity.md).

## Invocation

```text
chronicle-cli route preview -c examples/routing_config.yml \
  -t 'Review auth code' -i Review
chronicle-cli fork --from run.log --at 42 --out fork.log
chronicle-cli trace --file run.log --object claim#1
chronicle-cli chat
chronicle-cli quickstart
```

## Exit codes

The upstream CLI documents a structured exit-code table
(`EXIT_OK`=0, `EXIT_GENERIC_ERROR`=1, `EXIT_USAGE_ERROR`=2,
`EXIT_NOT_FOUND`=3, `EXIT_CORRUPTION`=4, `EXIT_DIVERGENCE`=5). The
Crystal CLI does **not** yet map errors to that table: `Chronicle::CLI.exec`
prints a human-readable `ERROR:` line and returns; the process exits 0
unless an exception escapes. Applications that need scriptable exit codes
should call the library APIs directly and branch on the raised exception
class (`Chronicle::InvalidLogEncodingError`,
`Chronicle::ReplayDivergenceError`, `Chronicle::EventNotFoundError`, …).

## Connection URLs

The library supports the SQLAlchemy-style store URL conventions (see
[store](api/store.md)):

```text
sqlite:///relative/path/to/run.db        # three slashes — relative
sqlite:////absolute/path/to/run.db       # four slashes — absolute
postgres://user:pass@host:port/dbname    # also accepted: postgresql://
```

Bare filesystem paths are rejected by `Chronicle.parse_store_url` with a
message naming the corrected URL (`InvalidStoreURL`).

The CLI's `fork`, `diff`, `trace`, and `replay` commands operate on
**encoded event-log files** produced by `Chronicle::EventLogCodec`
(`chronicle.event-log` format, version 1), not on store URLs.
`log inspect` and `replay` also accept a session-store file via
`Chronicle::SessionStore#load_store`.

## `--json` convention

The upstream CLI documents a stable `--json` output shape per
subcommand. Chronicle's CLI does **not** implement `--json`; the
underlying value objects are JSON-serializable, so programmatic callers
should use the library APIs directly (for example
`RuntimeStatus#to_h`, `Diff.compute(...)`, `PromotePlan`). This is a
documented divergence in [`plans/parity.md`](../../plans/parity.md).

## `route preview`

Preview a routing decision — no API call, no cost. Shows the classified
intent, the matched rule, and the selected model.

```text
chronicle-cli route preview --config <path> --text <text> [--intent <name>]
```

| Flag | Meaning |
| --- | --- |
| `-c`, `--config` | Routing policy YAML. Required. |
| `-t`, `--text` | Request text. Required. |
| `-i`, `--intent` | Optional explicit intent (`Chat`, `Plan`, `Edit`, `Review`, `Summarize`, `Prompt`, `Skill`). |

Prints `intent`, `matched_rule`, `provider/model`, `override_used`,
`fallback_used`, `confidence`, and the routing trace. Errors:
`NoRouteError` ("no eligible route") or `InvalidRoutingPolicyError`.

Programmatic equivalent:
`Routing::Router.new.preview(request, policy, available_targets)`.

---

## `log inspect`

Print the events in a log file.

```text
chronicle-cli log inspect --file <path>
```

Prints each event's sequence, type, id, actor, timestamp, optional
frame, and payload.

---

## `replay`

Replay an event log and show results (permissive mode).

```text
chronicle-cli replay --file <path>
```

Prints the event count, projected object/relation counts, and effect
count. `ReplayDivergenceError` is handled if the log diverges.

Programmatic equivalents: `Chronicle::ReplayEngine#replay(events,
ReplayMode::Permissive | ReplayMode::Strict)` and
`Chronicle::GraphProjection.replay(events)`. Strict-mode replay is a
library call, not a CLI flag.

---

## `fork`

Fork an event log at a given sequence point.

```text
chronicle-cli fork --from <log> --at <sequence> [--out <path>]
```

| Flag | Meaning |
| --- | --- |
| `-f`, `--from` | Source encoded event-log file. Required. |
| `-a`, `--at` | Sequence at which to fork (inclusive). Required. |
| `-o`, `--out` | Destination file. Defaults to `fork_at_<seq>.log` beside the source. |

Programmatic equivalent: `EventLogCodec.decode(File.read(path))`, then
`EventLog#fork_at(sequence)` and `EventLogCodec.encode(fork)`. For a
run-level fork that copies a run in a SQLite store, use
`Runtime#fork(at_event)` or `SQLiteEventStore.fork_run`.

---

## `diff`

Compare two encoded event logs.

```text
chronicle-cli diff --before <log> --after <log>
```

Prints shared / parent-only / fork-only event counts and the divergent
objects and relations with summaries.

Programmatic equivalent:
`Diff.compute(after_projection, before_projection, parent_events:,
fork_events:, parent_run_id:, fork_run_id:)`.

---

## `trace`

Render a causal chain from an object back to its goal, walking
`caused_by` links.

```text
chronicle-cli trace --file <log> --object <id>
```

| Flag | Meaning |
| --- | --- |
| `-f`, `--file` | Encoded event-log file. Required. |
| `-o`, `--object` | Root object id. Required. |

Programmatic equivalent:
`Trace.causal_chain(events, GraphProjection.replay(events), object_id)`.

---

## `session list`

List saved sessions under `Chronicle::SessionStore.default_dir`.

```text
chronicle-cli session list
```

Programmatic equivalent: `SessionStore.new(SessionStore.default_dir).list`.

---

## `fork`-and-`diff` / promote (library)

The upstream fork-and-diff cookbook workflow maps to:

- `Runtime#fork(at_event, label)` — durable parallel-context primitive
  (SQLite-backed runtime only).
- `Runtime#diff(other)` — structural comparison.
- `Runtime#promote(fork, dry_run:)` — apply a fork's net structural
  delta to its parent (fail-closed and atomic). There is no CLI
  `promote` subcommand; call the library.

---

## `chat`

Start an interactive chat session. Uses the configured routing policy
when present; otherwise the DeepSeek provider. The runtime executes
selected targets through the Crig `ModelEffectWorker`.

```text
chronicle-cli chat
```

Set a key before running:

```bash
export CLARITY_DEEPSEEK_API_KEY=sk-...
chronicle-cli chat
```

## `quickstart`

Run the bundled, offline, fixture-backed Diligence demo.

```text
chronicle-cli quickstart
```

Default mode uses bundled fixtures, no API key, and no network. The
transcript includes the canonical trace, one memo rendered in full, a
"what just happened" section, and next-step links. Programmatic
equivalent: `Chronicle::Quickstart.fixture_mode_lines`.

---

## Library-only operations

The following upstream subcommands have library equivalents rather than
CLI commands:

| Upstream command | Chronicle API |
| --- | --- |
| `migrate` | `Chronicle::Migration.migrate(source_url, dest_url, only_run_ids:)` |
| `pack new` | `Chronicle::Packs::Scaffold.scaffold_pack(target_dir, name)` |
| `pack list` | `Chronicle::Packs.discover` |
| `export-trace` (JSONL) | `Runtime#export_trace` and `TraceFacade#lines` |
| `promote` | `Runtime#promote(fork, dry_run:)` |
